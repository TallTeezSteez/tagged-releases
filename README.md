# Tagged downloads

One app to run the house. Sign-in is invite only.

## Download

- **Windows:** [Tagged-Setup.exe](https://github.com/TallTeezSteez/tagged-releases/releases/latest/download/Tagged-Setup.exe)

These links always get the newest version. Older versions: [all releases](https://github.com/TallTeezSteez/tagged-releases/releases).

**First time:**
1. Run the installer.
2. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**. You only do this once.

Tagged updates itself after that.

More about Tagged, with screenshots: https://draftline-gules.vercel.app/tagged

The `app/` folder is the small window around the live site that the installer is built from. The Tagged app itself isn't here.

## How a new version goes out

**Actions > Release > Run workflow.** Leave the version blank for the next number; add a line of "What's new" if you like. It builds and publishes on GitHub's free machines, and installed copies update themselves.

This repo is public so the downloads work for everyone. The app's code is in a private repo and isn't here.
